2. Login

POST

http://localhost:8082/api/v1/users/login

Use one of your seeded users.

{
    "email": "john@schedow.com",
    "password": "password123"
}

or

{
    "email": "admin@schedow.com",
    "password": "password123"
}
3. Create Shift

POST

http://localhost:8084/api/v1/schedules/shifts
{
    "name": "Late Night Shift",
    "startTime": "22:00",
    "endTime": "06:00"
}
4. Create Weekly Assignment

POST

http://localhost:8084/api/v1/schedules/assignments
{
    "weekStartDate": "2026-06-29",
    "dayOfWeek": "MONDAY",
    "assignedUserId": 1,
    "shiftId": 1
}
5. Create Unavailability

POST

http://localhost:8084/api/v1/schedules/unavailability
{
    "userId": 2,
    "unavailableDate": "2026-06-29",
    "startTime": "09:00",
    "endTime": "17:00",
    "reason": "Medical Appointment"
}
6. Create Recurring Assignment

POST

http://localhost:8084/api/v1/schedules/recurring-assignments
{
    "userId": 4,
    "dayOfWeek": "MONDAY",
    "shiftId": 2
}
7. Get Shift Recommendations

POST

http://localhost:8084/api/v1/schedules/recommendations
{
    "shiftId": 1,
    "dayOfWeek": "MONDAY",
    "date": "2026-06-29"
}
