# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records (ADRs) for Schedow.

Each ADR documents:

* a technical or architectural decision
* the reasoning behind it
* tradeoffs considered
* future implications

Examples:

* why microservices were chosen
* why REST was used before Kafka
* database-per-service strategy
* concurrency handling approaches

Purpose:
To maintain a historical record of important engineering decisions throughout the project lifecycle.
